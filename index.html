02

Papers

Venues, code, and abstracts. First-author work is marked.

  1. 2026

    ACM Transactions on Intelligent Systems and Technology · also NeurIPS 2025 workshop

    HumaniBench: A Human-Centric Framework for Large Multimodal Models Evaluation

    Shaina Raza, Aravind Narayanan, Vahid Reza Khazaie, Ashmal Vayani, Ahmed Y. Radwan, Mukund S. Chettiar, Amandeep Singh, Mubarak Shah, Deval Pandya

    arXiv ACM Site Code

    HumaniBench evaluates large multimodal models on human-centered principles with 32,000 expert-verified image–question pairs from news imagery. Across 15 models, proprietary systems lead on ethics, reasoning, and empathy, while open-source models are stronger on visual grounding and resilience — with persistent gaps in fairness and multilingual inclusivity.

  2. 2026

    NeurIPS 2026 workshop · AABA4ET first author

    AgentFinVQA: An Auditable, On-Premise Multi-Agent Pipeline for Financial Chart QA

    Aravind Narayanan, Shaina Raza

    arXiv Site Code

    Financial chart QA in regulated settings needs more than accuracy. AgentFinVQA decomposes each query into planning, OCR, legend grounding, visual inspection, and verification, recording a Model Evaluation Packet per sample. On FinMME it improves +7.68 pp over a matched zero-shot baseline while remaining auditable and on-premise deployable.

  3. 2026

    NeurIPS 2026 workshop · Trust-AI-Eval

    Stress-Testing Efficient Responsible-AI Evaluation: When Compute Savings Change Benchmark Conclusions

    Ahmed El Kady, Aravind Narayanan, Rehana Noorani, Yani Ioannou, Shaina Raza

    arXiv Site Code

    Making evaluation cheaper is treated as an implementation detail. We show it is a measurement intervention: batching largely preserves quality, while aggressive benchmark reduction can change the conclusions a responsible-AI benchmark is meant to support.

  4. 2026

    Journal of Open Source Software first author

    FairSense-AgentiX: An Agentic Platform for Multi-Modal Fairness and AI Risk Analysis

    Aravind Narayanan, Karanpal Sekhon, Mahshid Alinoori, Shaina Raza

    JOSS Code

    FairSense-AgentiX is an open-source agentic platform for analyzing text, images, and datasets for fairness and AI risk. A reasoning agent plans, selects tools, critiques its own outputs, and iterates — rather than relying on a single static classifier.

  5. 2026

    Future Technologies Conference

    From Features to Actions: Explainability in Traditional and Agentic AI Systems

    Sindhuja Chaduvula, Jessee Ho, Kina Kim, Aravind Narayanan, Ahmed Y. Radwan, Mahshid Alinoori, Muskan Garg, Dhanesh Ramachandram, Shaina Raza

    arXiv Site

    Attribution methods such as SHAP and LIME are stable for static predictions, but they cannot diagnose execution-level failures in multi-step agentic trajectories. We compare them with trace-based diagnostics as AI systems move from features to actions.

  6. 2025

    Information Fusion

    VLDBench: Evaluating Multimodal Disinformation with Regulatory Alignment

    Shaina Raza, Ashmal Vayani, Aditya Jain, Aravind Narayanan, Vahid Reza Khazaie, Syed Raza Bashir, Elham Dolatabadi, Gias Uddin, Christos Emmanouilidis, Rizwan Qureshi, Mubarak Shah

    arXiv Site Code

    VLDBench is a 62,000-pair benchmark for unimodal and multimodal disinformation detection, curated from 58 news outlets. Visual cues improve detection accuracy by 5 to 35 points over text-only models.

  7. 2025

    NeurIPS 2025 LLM Evaluation Workshop first author

    Bias in the Picture: Benchmarking VLMs with Social-Cue News Images and LLM-as-Judge Assessment

    Aravind Narayanan, Vahid Reza Khazaie, Shaina Raza

    arXiv

    A 1,343-pair news-image benchmark for social bias in VLMs. Visual context systematically shifts model outputs; higher faithfulness does not necessarily mean lower bias.

  8. 2025

    ASONAM 2025 · also NeurIPS 2025 workshop

    LinguaMark: Do Multimodal Models Speak Fairly? A Benchmark-Based Evaluation

    Ananya Raval, Aravind Narayanan, Vahid Reza Khazaie, Shaina Raza

    arXiv Site Code

    LinguaMark evaluates multilingual visual question answering with 6,875 image–text pairs spanning 11 languages and five social attributes, using bias, relevancy, and faithfulness as complementary metrics.

  9. 2024

    Toronto Robotics Conference

    Monocular Depth Estimation of Human-Robot Walking Environments using Deep Learning

    Andrew Qiu, Aravind Narayanan, Qilong Cheng, Brokoslaw Laschowski

    Lab

    A monocular depth model for reconstructing 3D walking environments from RGB, with an initial application to stair height and distance. On a RealSense-captured dataset it reached 82.6% stair-height accuracy and 81.4% depth accuracy versus ground-truth measurements.
